These are four Python console projects built during my 4-week internship. Python programs run in a terminal, so this page shows what each one does. The full code is on GitHub.

View code on GitHub

Task 1: Hangman Game

Guess the hidden word letter by letter with ASCII gallows art, 6 mistakes allowed, and no penalty for repeated guesses.

randomsets Run: python hangman.py

Task 2: Stock Portfolio Tracker

Calculates portfolio value and percentage gain or loss per stock, then saves a CSV summary.

csvfile I/O Run: python portfolio.py

Task 3: File Organizer

Sorts a messy folder into Documents, Images, Videos and more, handling duplicate names and permission errors.

pathlibshutil Run: python organizer.py FOLDER

Task 4: Rule-Based Chatbot

Answers FAQs using regex keyword matching, understands several questions at once, and exits on bye, exit or quit.

rejson Run: python chatbot.py
